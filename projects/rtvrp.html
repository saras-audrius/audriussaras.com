Real-time route optimisation.

A vehicle routing platform that re-optimises routes continuously on live event streams, built on Fabric Real-Time Intelligence.

What it is

With a couple of colleagues I built a real-time vehicle routing (VRP) optimisation platform on Microsoft Fabric's Real-Time Intelligence hub. Events flow in through Kafka and Azure Event Hubs, land in an Eventstream, get stored and queried in an Eventhouse with KQL, and surface on real-time dashboards with activators triggering downstream actions.

The project used most of the Fabric Real-Time Intelligence stack. Two colleagues presented the solution at Microsoft FabCon 2026 in Atlanta. I co-built the platform and mentored them, helping heavily with the development of the solution.

fig. illustration: routes update as events stream in.

The work

  • Co-built the streaming backbone: Kafka and Azure Event Hubs feeding Fabric Eventstream
  • Eventhouse storage with KQL queries powering live views of the routing state
  • Real-time dashboards and activators turning stream conditions into actions
  • Continuous VRP re-optimisation on top of the live event flow
  • Mentored the two consultants who presented it at Microsoft FabCon 2026 in Atlanta

Concepts

Fabric Real-Time Intelligence Eventhouse Kafka Azure Event Hubs Eventstream KQL Activators VRP

Key takeaway

Streaming data needs a different design from batch pipelines: routes have to be updated continuously as new events arrive, not once a day.
