AI agents for quote-to-cash.

Helping a global specialty-ingredients distributor choose its target AI architecture, and building the agents that automate quote-to-cash.

What it is

Quote-to-cash is the path from a customer's quote request to an order and, eventually, payment. A lot of it still runs through inboxes and PDFs. I'm advising the client on which AI architecture fits, and supporting the development of agents that read incoming documents and prepare the work that follows.

The project is in the proof-of-concept phase, with a production build to follow. Client details are confidential, so there are no screenshots here.

fig. the quote-to-cash flow, simplified. no client data.

The work

  • Advising on the target AI architecture
  • Agents built with Microsoft Foundry and Copilot Studio
  • Intelligent document processing to read incoming documents
  • Azure Functions and Logic Apps to connect the pieces
